# DynamisGPU 1.2.0 (unreleased)

Draft notes, collected as the work lands. Version 1.2.0 takes over the GPU data-layout code from Vectrix, adds a
Slang shader toolchain and kernel error buffers, and runs the hardware suites in CI. Like 1.1.0, it is distributed
through GitHub and local Maven installation, not Maven Central.

## New

- **GPU data layouts, moved from Vectrix** ([GPU data layouts](../gpu-data-layouts.md)):
  - **`ShaderLayout`** (`dynamis-gpu-api`, `org.dynamisengine.gpu.api.layout`): std140, std430 and scalar
    block layouts with GLSL emission, checked against glslang's layouts (the golden and its script came with it).
  - **`dynamis-gpu-vectrix`:** a new module, the only one that depends on Vectrix (3.2.1). It holds
    `GpuTransformLayout`, `GpuTransformWriteKernels` and `InstanceSubmissionPipeline`
    (`org.dynamisengine.gpu.vectrix`).
    - **Unchanged:** behaviour and tests are as in Vectrix.
    - **Renamed property:** `InstanceSubmissionPipeline`'s system property is now
      `dynamisgpu.instanceSubmission.forceMatrix`. The old `vectrix.runtime.instanceSubmission.forceMatrix` still
      works.
  - **`VertexFormat`:** gains the formats Vectrix's vertex layout had and DynamisGPU lacked: `FLOAT16X4`,
    `UNORM16X2`, `UNORM16X4`, `SNORM16X2`, `UINT32X1` to `UINT32X4`, `UINT8X2`, `INT8X2`, `UNORM8X2` and
    `SNORM8X2`.
- **Kernel error buffers:** `KernelErrors`, `ComputeException.Code.KERNEL_ERROR`, and `GpuCommandEncoder.resetErrors`
  and `checkErrors`. Kernels report data-dependent errors without poisoning the queue; shader helpers come in GLSL,
  Metal and Slang.
- **Shader toolchain:** the `dynamis-gpu-shaders` module (`ShaderBuild`) compiles Slang to SPIR-V and Metal with the
  rounding rules in [compute-runtime.md](../compute-runtime.md) and writes a manifest. `KernelLibrary`
  (`dynamis-gpu-api`) loads that manifest at runtime.
- **CI:** the Metal and MoltenVK suites run on a self-hosted Apple GPU runner, for pushes.

## Deprecated

- **`VertexFormat.UINT8X4_NORM`:** it is the same format as `UNORM8X4`; use that.

## Install and consume

New artifact: `dynamis-gpu-vectrix`. Add it only where code writes GPU data from Vectrix types.
