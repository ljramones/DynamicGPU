# DynamisGPU 1.3.0 (unreleased)

Draft notes, collected as the work lands.

## New

- **GPU timestamps:** `GpuSubmission.gpuTime()` gives a completed submission's GPU execution time.
  - **Where it's reported:** `GpuCapabilities.timestamps()` is now true where the device can measure it: native Metal,
    MoltenVK and lavapipe. See [compute-runtime.md](../compute-runtime.md).
  - **Benchmark:** the `GemmF16` benchmark reports GFLOP/s by GPU time.

## Behaviour changes to check

- **Metal bridge ABI 3:** it adds `dg_gpu_seconds`. A bridge built from 1.2 sources is refused with an ABI mismatch.
- **Vulkan query pools:** each Vulkan submission creates a two-entry timestamp query pool where the queue supports
  timestamps.
